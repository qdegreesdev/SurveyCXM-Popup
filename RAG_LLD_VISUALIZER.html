Multi-Stage Hybrid Pipeline Specifications

  • Dense Retrieval: ChromaDB with 384-d local ONNX vectors for high-level semantic context.
  • Sparse Retrieval: In-memory Okapi BM25 ($k_1=1.5, b=0.75$) catching technical placeholders like {{FIRST_NAME}} and UI buttons.
  • Reciprocal Rank Fusion (RRF): Merges rankings with $k=60$; double-hits automatically rise to rank #1.
  • FlashRank Cross-Encoder: Evaluates query and passages jointly in ~3.28ms, increasing accuracy by 25-35%.

Chunk Partitioning Rules

  • Header Preservation: Identifies sections with re.compile(r'<h([1-4])[^>]*>(.*?)</h\1>').
  • Size Guard: Sections over 3,500 characters undergo paragraph and line-level splitting into ~2,200 character units.
  • Prefixing: Every chunk is stamped with Module: [Name] and Section: [Title] for dense retrieval accuracy.

Streaming Architecture Highlights

  • Time-To-First-Token: Drops from ~2.2s down to < 250 ms.
  • Proxy Buffer Bypass: X-Accel-Buffering: no header prevents Nginx reverse-proxies from buffering chunks.
  • Standard Event Wire Protocol: data: {"token": "..."}\n\n compatible with modern web standard ReadableStream readers.
